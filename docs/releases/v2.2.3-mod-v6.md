# JQ Viewer 2.2.3 mod v6

- 发布版本：2.2.3 mod v6
- 基于：上游 JQ Viewer 2.2.3（JUKOMU/JQ-Viewer，commit 707278c，MIT License）
- 日期：2026-11-23
- 安装包：`JQViewer_2.2.3_mod_v6.apk`（约 29.9 MiB）
- SHA-256：`d421425169edd61b150ad211595473beb0f3f99a165c460b7a2449c8d89214b7`

## 本版改动

- 新增可用线路，API 线路固定为当前可用的 8 条。
- 图片线路探测改为多路并发：4 路分批，每条线路 5 张图 × 2 轮，优先返回首个可用线路，缩短首图等待时间。
- 其余功能与上游 2.2.3 保持一致，未改动界面与业务逻辑。

## 安装说明

- 支持 Android 7.0 及以上。
- 安装包签名与上游发行版不同，已安装原版时需先卸载再安装；卸载会清除应用内收藏与设置，建议提前备份。
- 首次启动如提示线路探测失败，可在设置中手动切换线路后重试。

## 校验方式

```bash
sha256sum JQViewer_2.2.3_mod_v6.apk
```

应输出上面的 SHA-256 值。
