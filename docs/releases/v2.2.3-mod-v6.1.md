# JQ Viewer 2.2.3 优化线路版 V6.1

- 发布版本：2.2.3 mod v6.1
- 基于：上游 JQ Viewer 2.2.3（JUKOMU/JQ-Viewer，MIT License）
- 日期：2026-11-24
- 发布仓库：https://github.com/hbfnjbb/JQ-Viewer

## 本次修正

- API 线路删除不可达的 `www.cdnawc.net`。
- `www.cdnhik.net` 修正为 `www.cdnhjk.net`。
- 图片线路新增 `cdn-msp3.jmapiproxy1.cc`。
- 最终内置清单：API 7 条，图片 12 条。
- 继续保留 V6 的“跳过远端 API 覆盖、域名状态去重、图片测速 4 路并发”。

## API 线路（7 条）

`www.cdnbtd.cc`、`www.cdnutc.cc`、`www.cdngwc.net`、`www.cdngwc.club`、`www.cdngwc.cc`、`www.cdnhjk.net`、`www.cdnutc.me`

## 图片线路（12 条）

`cdn-msp.jmapiproxy1.cc`、`cdn-msp.jmapiproxy2.cc`、`cdn-msp2.jmapiproxy2.cc`、`cdn-msp3.jmapiproxy2.cc`、`cdn-msp3.jmapiproxy1.cc`、`cdn-msp.jmapinodeudzn.net`、`cdn-msp3.jmapinodeudzn.net`、`cdn-msp.jmapiproxy3.cc`、`cdn-msp2.jmapiproxy3.cc`、`cdn-msp2.jmdanjonproxy.vip`、`cdn-msp.jmdanjonproxy.xyz`、`cdn-msp2.jmdanjonproxy.xyz`

客户端原有逻辑可能会把服务端下发的 `cdn-msp.jmdanjonproxy.vip` 追加到图片线路，因此运行期实际列表可能比内置 12 条多一条。
